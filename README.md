# Dẫn Đường Việt

Ứng dụng dẫn đường cho Android 8 trở lên: bản đồ, ảnh vệ tinh nét cao, tìm địa điểm, chỉ đường từng bước, đọc hướng dẫn bằng giọng tiếng Việt, tự tìm đường mới khi đi lệch.

**Tải APK:** vào mục *Releases* → `latest` → tải `DanDuongViet.apk`.

Dữ liệu: bản đồ © OpenStreetMap, ảnh vệ tinh © Esri, tìm đường OSRM, tìm kiếm Nominatim.
